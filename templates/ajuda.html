{{ s.titulo }}

{% if s.id == 'inicio' %}

O Início reúne atalhos e indicadores das áreas que você pode acessar. Clique nos indicadores que têm link para abrir a lista correspondente.

Valor não informado significa que o cadastro não traz esse dado. Valor zero é um valor cadastrado, igual a R$ 0,00. Os dois casos têm filtros separados na Análise.

{% elif s.id == 'pesquisa' %}

Use a lupa do cabeçalho em qualquer tela em que ela estiver disponível. Digite o número de patrimônio para abrir a ficha ou palavras para procurar bens, pessoas e centros de custo.

Com várias palavras, todas precisam aparecer no resultado. Use GEX* para começar com GEX e *ITEC para terminar com ITEC. A ficha mostra dados do bem e histórico disponível para suas funções.

{% elif s.id == 'termos' %}

O termo por centro de custo reúne os bens ativos sob a guarda do setor, excluindo os atribuídos individualmente. O termo individual reúne os bens da pessoa. O termo de devolução registra os bens que retornam ao patrimônio.

Abra as telas de termos para consultar os documentos e o histórico. Um termo pode estar vigente, desatualizado ou ainda não ter sido emitido.

{% if pode('termo_docx') %}

Para emitir, é necessário um processo SEI vigente do tipo correspondente. Confira o documento e use Emitir Termo no SEI: o sistema cria o documento no processo, inclui no bloco de assinatura "Termos {unidade}" e registra documento e bloco. Copiar para o SEI e Baixar .docx continuam disponíveis para fazer à mão. As três ações registram a emissão; abrir a prévia não registra.

Em Termos emitidos, acompanhe a emissão e, quando concluída, use Enviar email: abre seu programa de e-mail com o pedido de assinatura pronto. Termo individual e de devolução exigem a unidade SEI da pessoa (Cadastros → Pessoas). A emissão anterior permanece no histórico.

{% endif %} {% elif s.id == 'analise' %}

Filtre por situação, centro, pessoa, localização, classificação, idade, data de entrada, faixa de valor e situação do valor. Os indicadores representam o conjunto filtrado inteiro.

Os gráficos e indicadores com link refinam a seleção. Valor não informado e valor zero são filtros diferentes. Combinar valor não informado com um intervalo numérico não retorna bens.

Exportar .xlsx baixa todos os bens filtrados, mesmo quando a tela limita a lista a 1.000. Célula vazia de valor indica ausência de informação; zero permanece um número.

Abrir termo completo leva ao documento integral do centro ou da pessoa. Os filtros desta análise não limitam o termo.

{% elif s.id == 'inventario' %}

A função Inventário permite conferir bens nos eventos em que você integra a comissão. Sem evento atribuído, solicite ao administrador sua inclusão. Evento encerrado aceita somente consulta.

  1. Abra o evento e escolha a sala que está conferindo.
  2. Leia a plaqueta pelo leitor de código de barras, pela câmera ou digitando o número.
  3. Confira conservação, quem usa o bem e observações; acrescente as fotos necessárias.
  4. Acompanhe os bens pendentes e as divergências da sala.

Localizado foi lido na sala cadastrada; divergente foi lido em outra sala; pendente ainda não foi lido. A conferência não muda o cadastro de localização do sistema de patrimônio. Bens baixados continuam baixados.

Se a plaqueta não existir no cadastro, registre uma sobra com descrição, observação e foto quando o recurso estiver disponível. Para plaquetas ilegíveis, use a marcação em lote após conferir os bens.

Desmarcar remove a leitura e as fotos associadas. Se leu na sala errada, leia novamente na sala correta; vale a leitura mais recente.

{% if pode('inventario.abrir','POST') %}

O administrador abre o evento, define a comissão e o escopo das salas. Só pode haver um evento aberto. Encerrar congela os registros; excluir pede confirmação pelo nome e não pode ser desfeito.

{% endif %} {% elif s.id == 'consulta-inventarios' %}

A função Consulta de inventários permite acompanhar todos os eventos, anteriores e futuros, pelo Painel, Relatório e exportação. Ela não permite conferir bens por si só.

O Painel mostra o andamento e as distribuições do evento. No Relatório, filtre sala, situação, integrante, conservação, fotos e texto e use a ordenação das colunas.

Exporte a planilha com ou sem fotos. A opção com fotos usa recursos do Excel do Microsoft 365. Eventos encerrados preservam os registros congelados, mesmo depois de atualizar a base.

{% elif s.id == 'cadastros' %}

Centros de custo mantêm responsáveis e contatos. Localizações associam salas aos centros. Pessoas recebem bens de uso individual. Processos SEI definem o processo vigente de cada tipo de termo.

Use busca, filtros e paginação para encontrar registros. Revise origem e destino ao mover localizações ou atribuir bens. Bem atribuído a uma pessoa deixa de entrar no termo do setor.

{% if pode('responsaveis_excluir','POST') %}

Exclusões pedem confirmação. Centro com bens ativos e processo com termos registrados não podem ser excluídos.

{% endif %} {% if pode('importar_cadastros','POST') %}

A planilha de cadastros substitui as tabelas inteiras. As abas de inventário devem vir todas juntas ou ser omitidas. Importar nomes não concede acesso a usuários; revise a comissão do evento aberto.

{% endif %} {% elif s.id == 'textos' %}

Edite os dizeres dos termos e o modelo de e-mail. Preserve marcadores como {nome} e {ccustos}, preenchidos pelo sistema. Restaurar padrão recupera o texto original.

{% elif s.id == 'atualizar-base' %}

Envie o arquivo .xlsx exportado do sistema de patrimônio. A atualização substitui a base de bens e mantém os cadastros de responsáveis, pessoas e atribuições, conforme as validações apresentadas.

O histórico registra entradas, saídas e mudanças dos bens. Exportar bens gera uma planilha no formato de importação para cópia de segurança.

{% elif s.id == 'usuarios' %}

Crie usuários e selecione somente as funções necessárias. Administrador gerencia o sistema; Operador emite termos, mantém cadastros e textos e atualiza a base; Consulta lê acervo e termos; Inventário faz conferência na própria comissão; Consulta de inventários acompanha painéis, relatórios e exportações de todos os eventos.

As funções selecionadas se somam. Criar um usuário com Inventário não o inclui automaticamente em uma comissão. Login é único; o e-mail é opcional, único e também pode ser usado para entrar.

Usuários são inativados, não excluídos. Nova senha gera uma senha temporária mostrada uma única vez, com troca obrigatória no acesso seguinte. Cinco tentativas erradas bloqueiam o login por 15 minutos.

{% elif s.id == 'conta' %}

Seu nome e suas funções aparecem no cabeçalho. Para trocar a senha, informe a atual e a nova, com pelo menos oito caracteres. Sair encerra a sessão. A sessão expira após 12 horas sem uso.

Entraram ou saíram bens desde a última emissão. A equipe com função Operador pode conferir e emitir outro; o anterior permanece no histórico.

{% endif %} {% if pode('cadastros') %}

{% endif %} {% if pode('analise') %}

{% endif %} {% if pode('inventario.relatorio_tela') %}

Por que a atualização da base não mudou o evento encerrado?

O encerramento congela os dados do evento. Essa preservação permite consultar o que foi registrado naquele inventário.
